# 钓鱼高手 - 钓鱼收益追踪与社交钓鱼插件

## 简短描述

追踪钓鱼收益、与钓友实时互动、自动化繁琐钓鱼任务的全能钓鱼伴侣插件。

## 详细描述

**钓鱼高手 (FishingMaster)** 是一款专为钓鱼玩家设计的全能型插件，帮助你最大化钓鱼效率和收益。无论你是休闲钓鱼还是专业搬砖，这款插件都能提供追踪、分析和优化钓鱼活动所需的一切功能。

### ✨ 核心功能

**📊 实时收益仪表盘**

- 追踪单次和累计钓鱼收益
- 自动计算时薪（GPH），支持汇率换算人民币
- 显示最近拾取记录和时间戳
- 支持暂停/继续的计时器

**👥 渔友圈（社交功能）**

- 自动发现同服使用本插件的玩家
- 与钓友实时共享钓鱼统计数据
- 查看在线渔友列表和社区排名
- 社区共享的鱼价参考数据库

**📈 详细统计分析**

- 按区域/地图分类的钓鱼统计
- 每日收益趋势和历史记录
- 每件物品的拾取数量和收益明细
- 跨会话的历史数据追踪

**⚡ 便捷自动化功能**

- **快速拾取**：自动拾取钓鱼产出，无需手动点击
- **采集上马**：钓鱼后自动上马赶路
- **钓鱼横条**：钓鱼时屏幕顶部显示精简状态栏
- **互动范围提醒**：视觉提示保持最佳钓鱼距离

**⚙️ 个性化设置**

- 开关各项功能（快速拾取/互动提醒/角色切换音效等）
- 采集上马延迟设置（0.5-5秒）
- 金价汇率设置（支持换算人民币）
- 界面位置记忆（拖动后自动保存）

### 🎮 支持版本

- 魔兽世界经典怀旧服（WLK 3.3.5）
- 魔兽世界正式服（多版本兼容）

### 📋 命令说明

| 命令                    | 功能                |
| --------------------- | ----------------- |
| `/ls`                 | 打开/关闭主界面（导航栏式 UI） |
| `/fm`                 | 直接跳转到渔友圈页面        |
| `/sm` 或 `/smartmount` | 打开采集上马设置          |

**小地图按钮**：点击小地图旁的鱼图标也可打开主界面。

### 🛠️ 安装方法

1. 下载插件压缩包
2. 解压到 `World of Warcraft\_classic_\Interface\AddOns\` 目录
3. 确保文件夹名称为 `FishingMaster`
4. 进入游戏，在插件列表中勾选"钓鱼高手"

### ⚠️ 已知问题 / 注意事项

- 渔友圈功能需要同服玩家也安装本插件才能共享数据
- 首次使用请先在设置中配置金价汇率，否则时薪计算会显示为 0
- 钓鱼横条位置可拖动，拖动后会自动保存
